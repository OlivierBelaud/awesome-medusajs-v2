# Contributing

Open an issue or pull request with the resource name, its canonical public URL, and a short description of what it does. If you maintain the resource or worked on the project, mention your role.

- For a plugin, starter, or theme, link to upstream documentation, a release, or a manifest that establishes Medusa v2 compatibility. Include a minimum version or version range when the source specifies one.
- For an integration listed by Medusa, use its directory entry and the publisher classification Medusa gives it. For a standalone community package, link to the maintainer's repository or package.
- For an Expert agency, link to its live Medusa Experts profile. For a production project, link to a public source that identifies the project and its Medusa v2 implementation, and credit the implementation team.
- For removals or replacements, explain what changed and link to the upstream announcement or successor where available.
